# LHC Event Filter & Analyzer

A high-performance C simulation of a Data Acquisition System (DAQ) for particle physics experiments. This project simulates the generation, filtering, and statistical analysis of collision events (like those at the Large Hadron Collider).

## Overview
This project consists of two main components communicating via **Unix Pipes**:
1.  **Generator:** Produces a stream of synthetic particle data (Protons, Higgs Bosons, Muons, etc.) with randomized energy and timestamps.
2.  **Analyzer:** Reads the stream in real-time, stores data using **dynamic memory allocation**, and performs statistical analysis.

## Key Technical Features
* **Dynamic Memory Management:** Implements a custom dynamic array with exponential growth strategy (doubling capacity) using `realloc` to handle unknown data volumes efficiently.
* **Stream Processing:** Uses Standard Input/Output (`stdin`/`stdout`) to allow modular pipelining of data (`|`).
* **Data Parsing:** robust string parsing using `fgets` and `sscanf` with error handling.
* **Statistical Analysis:** Calculates mean energy, peak signal detection, and specific particle filtering (e.g., Higgs boson detection).
* **Modular Architecture:** Separation of concerns using header files (`.h`), source files (`.c`), and a robust `Makefile`.

## Project Structure
```text
.
├── src/            # Source code (.c)
│   ├── generator.c # Data simulation tool
│   ├── analyzer.c  # Main entry point for analysis
│   └── events.c    # Core logic (memory & statistics)
├── include/        # Header files (.h)
├── bin/            # Executables (generated by make)
├── obj/            # Object files (generated by make)
└── Makefile        # Compilation automation
```

## How to Build
The project uses a standard `Makefile`. Ensure you have gcc and make installed

```bash
# Compile the project
make

# Clean up build artifacts
make clean
```

This will generate two executables in the bin/ directory:
* `generator`: Creates synthetic collision data.
* `analyzer`: Processes and filters the events.

## How to Run
You can run the components individually or pipe them together for the full simulation.

**1. The Full Pipeline (Recommended)**
```bash
./bin/generator 10000 | ./bin/analyzer
```

**2. Manual Mode (Using files)**
```bash
#Generate data to a file
./bin/generator 5000 > data.txt

#Analyze the file
./bin/analyzer < data.txt
```
